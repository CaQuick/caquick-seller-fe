## 시안 대비 남은 차이

승인 시안(seller-design-v6)과 다르게 구현한 곳입니다. 대부분 API에 필드가 없거나 공용 부품 규칙을 따른 결과라, 시안대로 바꾸려면 괄호 안의 이유를 먼저 풀어야 합니다.

- 공통
  - 토큰에 없는 시안 hex는 가장 가까운 토큰으로 그립니다(셀렉트 값·드롭존·태그 ×·chevron·옵션 아이템 테두리·매장 메타 글자). 홈 히어로 그라디언트도 `stepDone → tint2 → bg → gray2`로 근사해 오른쪽 위 크림색이 회색 쪽입니다.
  - 토스트는 공용 sonner 스타일 한 줄입니다. 어두운 토스트, 두 줄짜리 새 주문 토스트, '되돌리기' 액션(특별휴무·옵션 아이템 삭제)은 없습니다(`showToast`에 액션 없음).
  - 44pt 터치 타깃을 위해 작은 컨트롤은 `hitSlop`을 더하고 `TimeRow` 칸은 40 → 44입니다. `ActionBar`는 화면 맨 아래 정적 배치이고 아래 여백은 `max(safe area, 16)`입니다.
  - `Skeleton`은 그라디언트 흐름 대신 투명도 깜빡임, 스플래시 로딩 점은 400ms마다 한 점씩 켜는 근사입니다.
  - 탭 화면(주문·상품·매장)은 탭 레이아웃의 네이티브 헤더, 상세 화면은 공용 `AppHeader`, 설정의 비밀번호 변경은 Stack 헤더입니다. 홈 활성 탭 아이콘은 전용 채움 대신 다른 탭과 같은 '라인 + 연보라 채움'입니다.
- 인증
  - 로그인 잠금은 입력을 고치면 풀립니다(앱이 해제 시각을 모름). 정지 계정 로그인은 토스트 대신 비밀번호 아래 문구입니다.
- 홈
  - 시안에 없는 상태를 더했습니다: 생산 수량 미설정, 운영 중지, 필터 결과 없음.
- 주문
  - 목록에 '· N건'·'외 N건'이 없습니다(D35). 품목 행 이미지는 회색 자리 표시입니다(`OrderItemDetail`에 이미지 없음).
  - '요청 사항'은 자유 편집 요청마다 묶어 보여 줍니다(주문 전체 메모 필드 없음). 진행 이력의 주체는 접수에만 붙습니다(처리 주체 필드 없음).
  - 기간 선택(픽업일·주문일)은 시안이 없어 월 달력에서 시작일·종료일을 차례로 누르는 시트입니다. '필터 초기화'는 기본값이 아니라 모든 조건을 해제합니다.
- 상품
  - 카테고리 칩 행은 줄바꿈 대신 가로 스크롤, '구매자 화면으로 보기'는 상세 위 모달입니다.
  - 등록 1/3 '다음'은 필수값 전에도 누를 수 있고 누르면 빠진 항목을 알립니다. 태그 시트는 내용 높이 바텀시트이고 제안 목록, 등록 진행 시트, 이탈 확인 시트는 자유 설계입니다.
  - 3/3 썸네일 스트립은 `DetailGallery`(56 r8)를 재사용해 시안(55 r5)과 1px·반경이 다릅니다.
  - 옵션 아이템 순서는 위/아래 버튼입니다(그룹 끌기와 제스처 충돌). 제작 소요 시간은 1분 이상입니다(BE 최소 1). 수정 저장 실패는 폼 상단 대신 토스트입니다.
  - 커스텀 문구 슬롯은 표시 이름 필드가 없어 치환 키를 라벨로 쓰고, 좌표는 베이스 이미지 한 변 10,000 기준 비율입니다. 베이스 이미지가 없으면 슬롯 추가·저장을 막습니다.
- 채팅
  - 목록 시각은 시안 예시를 따라 사흘 전도 날짜로 씁니다. 입력바는 여러 줄로 늘어나고, 시스템 메시지는 회색 가운데 알약입니다.
  - '주문 보기'는 닉네임이 정확히 같은 최신 주문으로 갑니다(주문 목록에 구매자 계정 필터 없음). 답변 필요 수는 불러온 페이지 안에서 셉니다.
- 매장
  - 일별 생산 수량에 '기본 수량'이 없습니다(BE 개념 없음, 미설정 날짜는 제한 없음). 수량 시트의 '이미 접수된 주문 n개'도 없습니다.
  - 픽업 정책 미리보기는 저장된 정책으로 그립니다(구매자 API가 저장값만 계산). 예약 불가 슬롯은 취소선 대신 비활성 칩입니다. 지역은 시군구 + 상위 광역까지입니다.
  - 현재 위치 권한을 거부해도 '현재 위치로 찾기'를 두고 설정 열기를 안내합니다(D47).
  - 자동응답 편집에 미리보기 섹션을 더했고, 답변 입력 최소 높이는 공용 `TextField`의 98px입니다.
  - 리뷰 카드에 옵션 줄이 없고 리뷰 상세의 상품 메타는 '옵션 · 가격'입니다(픽업일·옵션 필드 없음).
  - 조작 이력 행 제목은 감사 로그에 남은 키로 영역만 고르고 나머지는 대상 id로 씁니다(표시용 스냅샷 없음). 미리보기의 상품 시트는 대표 이미지·가격·설명만 보여 줍니다.
- 설정
  - 알림 권한 행은 chevron과 칩을 함께 두는 전용 행이고, 업데이트 행 설명은 상태별 문구입니다.
